## 구현 방식

### JavaScript/TypeScript 배열
```javascript
// frontend/constants/messages.ts
export const ENCOURAGEMENT_MESSAGES = {
  basic: [
    "잘했어요! 오늘도 한 걸음 더 나아갔네요 🌱",
    // ... 30개 메시지
  ],
  timeOfDay: {
    morning: [...],   // 06:00-12:00
    afternoon: [...], // 12:00-18:00
    evening: [...],   // 18:00-22:00
    night: [...]      // 22:00-06:00
  },
  streak: {
    3: [...],
    5: [...],
    10: [...]
  },
  levelUp: {
    2: "새싹이 돋아났어요! 당신의 정성 덕분이에요 🌱",
    // ... 레벨별 메시지
  }
};

// 메시지 선택 로직
function getRandomMessage(category = 'basic') {
  const messages = ENCOURAGEMENT_MESSAGES[category];
  return messages[Math.floor(Math.random() * messages.length)];
}

// 시간대별 메시지 선택
function getTimeBasedMessage() {
  const hour = new Date().getHours();
  if (hour >= 6 && hour < 12) return getRandomMessage('timeOfDay.morning');
  if (hour >= 12 && hour < 18) return getRandomMessage('timeOfDay.afternoon');
  if (hour >= 18 && hour < 22) return getRandomMessage('timeOfDay.evening');
  return getRandomMessage('timeOfDay.night');
}
```

## 메시지 표시 가이드라인

### 표시 규칙
1. **기본**: 할 일 완료 시 기본 메시지 중 무작위 선택
2. **시간 고려**: 20% 확률로 시간대별 메시지 표시
3. **연속 보너스**: 연속 완료 시 특별 메시지 우선 표시
4. **레벨업**: 레벨업 시 해당 레벨 메시지 필수 표시

### 애니메이션
- **등장**: fadeIn + slideUp (0.5초)
- **유지**: 2-3초간 표시
- **퇴장**: fadeOut (0.5초)
- **위치**: 화면 상단 중앙 또는 바질 화분 위

### 스타일링
- **배경**: 반투명 흰색 또는 파스텔 톤
- **텍스트**: 부드러운 폰트, 읽기 쉬운 크기
- **그림자**: 부드러운 그림자로 depth 표현
- **아이콘**: 이모지 활용으로 친근감 증대
