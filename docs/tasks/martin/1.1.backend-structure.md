### 2. application.yml 설정 검증

#### 기본 설정
```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  application:
    name: todolist-backend

  # 데이터베이스 설정
  datasource:
    url: jdbc:mysql://localhost:3306/todolist?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver
    hikari:
      connection-timeout: 30000
      maximum-pool-size: 10

  # JPA 설정
  jpa:
    hibernate:
      ddl-auto: validate  # 개발 초기: create-drop, 이후: validate
    show-sql: true
    properties:
      hibernate:
        dialect: org.hibernate.dialect.MySQL8Dialect
        format_sql: true
    open-in-view: false

  # 액추에이터 설정 (health check용)
  actuator:
    endpoints:
      web:
        base-path: /actuator
        exposure:
          include: health,info

# 로깅 설정
logging:
  level:
    root: INFO
    com.study.todolist: DEBUG
  pattern:
    console: "%d{yyyy-MM-dd HH:mm:ss} - %msg%n"
```

### 3. 의존성 확인 (pom.xml 또는 build.gradle)

#### 필수 의존성
- spring-boot-starter-web
- spring-boot-starter-data-jpa
- mysql-connector-java
- spring-boot-starter-actuator
- spring-boot-starter-validation
- lombok (선택)

### 4. 프로젝트 실행 테스트
```bash
cd backend
./mvnw clean compile  # Maven
# 또는
./gradlew clean build  # Gradle

# 애플리케이션 실행
./mvnw spring-boot:run
# 또는
./gradlew bootRun
```
