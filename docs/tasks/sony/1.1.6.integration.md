### 1. CORS 설정 구성
위치: `backend/src/main/java/com/study/todolist/config/CorsConfig.java`

```java
package com.study.todolist.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.CorsConfigurationSource;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

import java.util.Arrays;

@Configuration
public class CorsConfig implements WebMvcConfigurer {

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
                .allowedOrigins(
                    "http://localhost:3000",      // Next.js 개발 서버
                    "http://localhost:3001",      // 대체 포트
                    "http://127.0.0.1:3000"       // localhost 대신 IP 사용 시
                )
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowedHeaders("*")
                .allowCredentials(true)
                .maxAge(3600);
    }
}
```

### 2. 통합 테스트 스크립트
위치: `scripts/integration-test.sh`

```bash
#!/bin/bash

echo "=== 통합 테스트 시작 ==="

# 1. MySQL 컨테이너 상태 확인
echo "1. MySQL 상태 확인..."
docker ps | grep mysql
if [ $? -ne 0 ]; then
    echo "❌ MySQL이 실행되지 않음. docker-compose up -d mysql 실행 필요"
    exit 1
fi
echo "✅ MySQL 실행 중"

# 2. 백엔드 서버 실행 확인
echo "2. 백엔드 서버 확인..."
curl -s http://localhost:8080/api/health > /dev/null
if [ $? -ne 0 ]; then
    echo "❌ 백엔드 서버가 응답하지 않음"
    echo "   backend 디렉토리에서 ./mvnw spring-boot:run 실행 필요"
    exit 1
fi
echo "✅ 백엔드 서버 응답 확인"

# 3. Health API 응답 확인
echo "3. Health API 테스트..."
HEALTH_RESPONSE=$(curl -s http://localhost:8080/api/health)
echo "응답: $HEALTH_RESPONSE"

# JSON 파싱하여 상태 확인
STATUS=$(echo $HEALTH_RESPONSE | grep -o '"status":"UP"')
if [ -n "$STATUS" ]; then
    echo "✅ Health API 정상"
else
    echo "❌ Health API 비정상"
    exit 1
fi

# 4. 프론트엔드 서버 확인
echo "4. 프론트엔드 서버 확인..."
curl -s http://localhost:3000 > /dev/null
if [ $? -ne 0 ]; then
    echo "❌ 프론트엔드 서버가 응답하지 않음"
    echo "   frontend 디렉토리에서 npm run dev 실행 필요"
    exit 1
fi
echo "✅ 프론트엔드 서버 응답 확인"

# 5. CORS 테스트
echo "5. CORS 설정 테스트..."
curl -H "Origin: http://localhost:3000" \
     -H "Access-Control-Request-Method: GET" \
     -H "Access-Control-Request-Headers: X-Requested-With" \
     -X OPTIONS \
     --verbose \
     http://localhost:8080/api/health 2>&1 | grep -i "access-control-allow-origin"

if [ $? -eq 0 ]; then
    echo "✅ CORS 설정 정상"
else
    echo "❌ CORS 설정 문제"
    exit 1
fi

echo ""
echo "=== 통합 테스트 완료 ==="
echo "✅ 모든 컴포넌트가 정상 작동 중입니다."
```

### 3. 시스템 통합 체크리스트

#### 실행 순서
1. **MySQL 시작**
   ```bash
   cd /path/to/project
   docker-compose up -d mysql
   # 10초 대기 (MySQL 초기화)
   sleep 10
   ```

2. **백엔드 서버 시작**
   ```bash
   cd backend
   ./mvnw spring-boot:run
   # 또는
   ./gradlew bootRun
   ```

3. **프론트엔드 서버 시작**
   ```bash
   cd frontend
   npm run dev
   ```

4. **통합 테스트 실행**
   ```bash
   ./scripts/integration-test.sh
   ```

### 4. 브라우저 테스트

#### 테스트 시나리오
1. 브라우저에서 http://localhost:3000 접속
2. 환영 페이지 로드 확인
3. 우측 상단 상태 표시기 확인:
   - 녹색 "정상 작동 중": 시스템 정상
   - 황색 "부분 작동": 일부 문제
   - 빨간색 "서버 연결 실패": 백엔드 문제

#### 개발자 도구 네트워크 탭 확인
- `/api/health` 요청이 200 OK 응답
- CORS 헤더 확인
- 10초마다 자동 health check 확인

### 5. 트러블슈팅 가이드

#### CORS 에러
```
Access to XMLHttpRequest at 'http://localhost:8080/api/health' from origin 'http://localhost:3000' has been blocked by CORS policy
```
**해결:** CorsConfig.java 확인 및 백엔드 재시작

#### Connection Refused
```
Error: connect ECONNREFUSED 127.0.0.1:8080
```
**해결:** 백엔드 서버 실행 확인

#### Database Connection Failed
```
"database": "DOWN"
```
**해결:** MySQL 컨테이너 실행 상태 확인
