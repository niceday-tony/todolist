# Story 1.1: 프로젝트 구조 설정 및 상태 확인

## Status
Draft

## Story
**As a** 개발자,
**I want** Spring Boot와 React를 모노레포 안에 설정하고, 데이터베이스 연결을 확인하며, 기본 상태 확인(health check) 엔드포인트를 만들어서,
**so that** 본격적인 기능 개발을 시작할 수 있는 안정적인 기반을 마련할 수 있다.

## Acceptance Criteria
1. Spring Boot와 React 프로젝트가 모노레포 구조 안에 생성된다.
2. 백엔드 애플리케이션이 시작될 때 MySQL 데이터베이스에 성공적으로 연결된다.
3. `/api/health` 엔드포인트에 GET 요청을 보내면 200 OK 응답을 받는다.
4. React 애플리케이션을 시작하면, 임시 환영 페이지가 화면에 표시된다.

### 기술 스택 정보
**백엔드** [Source: architecture/tech-stack.md#백엔드 기술 스택]
- Java 17 LTS
- Spring Boot 3.2.x
- MySQL 8.0 (Docker)
- Spring Data JPA

**프론트엔드** [Source: architecture/tech-stack.md#프론트엔드 기술 스택]
- Node.js 18.x LTS
- Next.js 14.x (App Router)
- React 18.x
- TypeScript 5.x
- Axios for HTTP

### 데이터베이스 설정
**MySQL Docker 설정** [Source: architecture/tech-stack.md#데이터베이스 설계]
```yaml
# docker-compose.yml (이미 존재)
version: '3.8'
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: todolist
    ports:
      - "3306:3306"
```
