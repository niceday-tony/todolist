# 4. 기술적 가정

- **리포지토리 구조:** Monorepo (모노레포)
- **서비스 아키텍처:** Monolith (모놀리식)
- **테스팅 요구사항:** Unit Only (단위 테스트만 진행)
- **추가 기술 가정:**
    - 애플리케이션은 Spring Boot 백엔드가 제공하는 단일 페이지 애플리케이션(SPA)으로 설계된다.
    - 데이터 영속성을 위해, `docker-compose.yml`에 명시된 대로 **MySQL 8.0 데이터베이스**를 사용한다. (`application.yml`에 해당 접속 정보가 설정되어 있음)
    - 배포는 백엔드와 프론트엔드 자산을 모두 포함하는 단일 실행 가능 JAR 파일로 진행한다. 이 애플리케이션은 Docker Compose를 통해 실행되는 MySQL 데이터베이스에 연결된다.
