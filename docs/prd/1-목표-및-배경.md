# 1. 목표 및 배경

## 목표
- 하루 안에 개발할 수 있는 "감성적인" 할 일 목록 웹 애플리케이션을 제공한다.
- 단순한 작업 관리를 넘어, 사용자에게 정서적 위안과 심리적 안정감을 준다.
- 사용자가 작업을 완료할 때마다 "작은 위로"를 받는 경험을 선사한다.
- 사용자가 성취감을 느끼고, 긴 업무 시간 동안 조금이나마 더 편안함을 느끼도록 돕는다.

## 배경
이 프로젝트는 많은 직장인들이 업무 시간 동안 느끼는 외로움과 정서적 지지의 필요성에서 출발했습니다. 우리는 할 일 목록이라는 일상적인 도구를, 매일의 작은 성공을 축하하고 위로를 주는 감성적인 경험으로 전환하고자 합니다. 사용자가 작업을 완료할 때마다 디지털 바질 화분이 자라나고 격려의 메시지가 나타나는 핵심 기능을 통해, 반복적인 업무에 긍정적인 감성을 불어넣고 사용자의 심리적 안정감에 기여하는 것을 목표로 합니다.
