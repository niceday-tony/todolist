# 6. 에픽 1: 상세 내용
**목표:** 풀스택(Spring/React) 프로젝트 구조를 설정하고, 기본적인 할 일 관리(CRUD) 기능을 구현하며, 사용자가 작업을 완료할 때마다 바질 화분이 성장하고 격려 메시지가 나타나는 핵심적인 '위로의 순환' 경험을 제공한다.

## 스토리 1.1: 프로젝트 구조 설정 및 상태 확인
- **As a** 개발자,
- **I want** Spring Boot와 React를 모노레포 안에 설정하고, 데이터베이스 연결을 확인하며, 기본 상태 확인(health check) 엔드포인트를 만들어서,
- **so that** 본격적인 기능 개발을 시작할 수 있는 안정적인 기반을 마련할 수 있다.

**완료 조건:**
1. Spring Boot와 React 프로젝트가 모노레포 구조 안에 생성된다.
2. 백엔드 애플리케이션이 시작될 때 MySQL 데이터베이스에 성공적으로 연결된다.
3. `/api/health` 엔드포인트에 GET 요청을 보내면 200 OK 응답을 받는다.
4. React 애플리케이션을 시작하면, 임시 환영 페이지가 화면에 표시된다.

## 스토리 1.2: 할 일(To-Do) 관리 API 구현
- **As a** 개발자,
- **I want** 할 일을 생성(Create), 조회(Read), 수정(Update)할 수 있는 백엔드 API를 만들어서,
- **so that** 프론트엔드에서 할 일 데이터를 관리할 수 있다.

**완료 조건:**
1. `POST /api/todos`: 요청 본문(request body)의 내용으로 새로운 할 일을 데이터베이스에 생성한다.
2. `GET /api/todos`: 데이터베이스에 있는 모든 할 일 목록을 조회한다.
3. `PUT /api/todos/{id}`: 특정 ID의 할 일 상태를 '완료'로 변경한다.

## 스토리 1.3: 기본 할 일 UI 구현
- **As a** 사용자,
- **I want** 할 일 목록을 보고, 새로운 할 일을 추가하고, 기존 할 일을 완료 처리할 수 있어서,
- **so that** 기본적인 할 일 관리 기능을 사용할 수 있다.

**완료 조건:**
1. 웹 애플리케이션이 로드될 때, 백엔드에서 할 일 목록을 가져와 화면에 표시한다.
2. 입력창에 텍스트를 입력하고 버튼을 클릭하여 새로운 할 일을 추가할 수 있다.
3. 새로운 할 일을 추가하면, 페이지 새로고침 없이 목록에 즉시 나타난다.
4. 목록에 있는 할 일의 체크박스나 버튼을 클릭하여 '완료' 상태로 변경할 수 있다.

## 스토리 1.4: '위로의 순환' 핵심 기능 구현
- **As a** 사용자,
- **I want** 할 일을 완료할 때마다 바질 화분이 자라고, 격려 메시지와 시각 효과가 나타나서,
- **so that** 작은 성취감을 느끼고 정서적인 위로를 받을 수 있다.

**완료 조건:**
1. 화면에 바질 화분 이미지가 항상 표시된다.
2. 할 일을 완료하면, 바질 화분 이미지가 약간 더 성장한 이미지로 변경된다.
3. 현재 화분의 성장 단계는 데이터베이스에 저장되어, 웹 애플리케이션을 다시 시작해도 유지된다.
4. 할 일을 완료하면, 미리 정의된 목록에서 무작위로 선택된 격려 메시지가 잠시 동안 화면에 표시된다.
5. 할 일을 완료하면, 반짝이는 효과와 같은 단순하고 기분 좋은 시각 효과가 나타난다.
