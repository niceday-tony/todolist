# 3. 사용자 인터페이스(UI) 디자인 목표

- **전반적인 UX 비전:** 따뜻하고, 미니멀하며, 위로를 주는 경험. 사용자가 웹사이트를 열 때마다 작은 정원을 가꾸는 듯한 평온함을 느끼게 한다.
- **핵심 상호작용 방식:** 직관적인 제스처 기반의 상호작용. 불필요한 클릭이나 복잡한 메뉴는 최소화한다.
- **핵심 화면 및 뷰:** 단일 화면 애플리케이션(Single Page Application)으로, 모든 기능(할 일 목록, 바질 화분)이 한 화면에 집중된다.
- **접근성:** WCAG AA
- **브랜딩:** 전체적으로 부드러운 파스텔 톤 또는 흙(earth-tone) 색상을 사용한다. 폰트는 손글씨체나 부드러운 느낌의 세리프체를 사용하여 아날로그 감성을 더한다.
- **대상 디바이스 및 플랫폼:** Web Responsive (웹 반응형)
