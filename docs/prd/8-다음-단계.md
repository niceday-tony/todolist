# 8. 다음 단계

## UX 전문가에게 전달할 프롬프트
> UX 전문가님, 첨부된 PRD(`docs/prd.md`)를 검토해 주십시오. 특히 3번 '사용자 인터페이스(UI) 디자인 목표' 섹션을 기반으로, '감성적인 할일 목록' 웹 애플리케이션의 와이어프레임과 핵심 상호작용에 대한 구체적인 디자인 시안을 제안해 주십시오. 사용자가 '작은 위로'를 느낄 수 있는 시각적 효과와 애니메이션에 대한 아이디어를 포함해 주세요.

## 아키텍트에게 전달할 프롬프트
> 아키텍트님, 첨부된 PRD(`docs/prd.md`)를 기반으로 '감성적인 할일 목록' 웹 애플리케이션의 전체 아키텍처 설계를 시작해 주십시오. PRD의 모든 요구사항과 기술적 가정을 충족하는 솔루션을 설계하고, 개발 환경 설정부터 배포까지의 상세 계획을 포함한 아키텍처 문서를 작성해 주십시오.
